# Инструкции для Claude Code

- Прочитай README.md и AGENTS.md перед изменениями. Открытые задачи — в `ROADMAP.md`.
- Ядро расчёта — `model.js`, `model-fronts.js`, `export.js`. Меняй логику только осознанно; после изменений проверь, что `production.html` и DXF/CSV по-прежнему открываются.
- Все размеры в ядре — миллиметры; в 3D (`build3d.js`) — метры.
- Интерфейс на русском языке.
- После правок ядра запускай `./run.sh test`; перед релизом — `./run.sh bump` и запись в `CHANGELOG.md`.
