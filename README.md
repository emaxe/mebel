# Конструктор корпусной мебели

Браузерный параметрический редактор корпусной мебели: шкафы, стеллажи, тумбы, комоды и кухни из нескольких модулей с 3D-просмотром, расчётом, технической документацией, экспортом под распил и проверкой собираемости.

Работает локально-first: без сервера достаточно открыть `web/`. При желании можно поднять синхронизацию проектов, версии, шаринг и каталог через `server/` (Fastify + Postgres).

## Быстрый старт

### Только клиент
```bash
./run.sh serve
# или
npx serve .
```

Открыть `http://localhost:3000` (или порт serve). Приложение хранит проекты в `localStorage`.

### Полный стек (клиент + API + БД)
```bash
./run.sh dev
```
- Клиент: http://localhost:8088
- API: http://localhost:8088/api
- Mailpit: http://localhost:8025

## Структура
| Путь | Назначение |
|---|---|
| `web/` | Клиент: UI, ядро расчёта, 3D, экспорт, смета, проверка собираемости |
| `server/` | API: авторизация, проекты, версии, шаринг, каталог, синхронизация |
| `deploy/` | Caddy + Docker Compose для деплоя |
| `test/` | Тесты ядра (Vitest) |
| `run.sh` | Скрипты запуска, тестов, проверки |
| `AGENTS.md` | Инструкция для AI-агентов |
| `CHANGELOG.md` | История изменений |

## Ключевые возможности
**Проектирование**
- Параметрический расчёт корпуса: детали, кромка, отверстия, пазы, конфирматы, эксцентрики, шканты, полкодержатели (`web/model.js`, `web/model-fronts.js`).
- Типы: шкаф (распашные двери и купе), стеллаж, тумба, комод, ТВ-тумба; кухня: нижний модуль, верхний модуль, пенал, фальшпанель, угловой модуль «Г» с глухим углом (двери в 3D неподвижные); угловая и П-образная раскладка, газлифты подъёмных фасадов подбираются по массе.
- Проект из нескольких модулей: ряд вдоль стены, «над предыдущим» для навесных, угол (второй ряд вдоль соседней стены), зазоры и подъём над полом (`web/project.js`).
- Столешница над нижними модулями с вырезами под мойку и варочную панель, бортиком и фартуком из ХДФ, цокольная планка на клипсах, царги вместо крышки.
- Правка прямо в 3D: выбор детали, размерные линии с вводом размера кликом, перетаскивание полок с привязкой к шагу 32 мм, «вписать в нишу» по общей ширине.
- Нестандартные детали: вырезы, выемки, скосы и скругления углов; радиусные торцы боковин.
- Помещение проекта: стены, потолок, окна и двери, плинтус; проверка выхода за стены и потолок, шкафов в проёмах, вид в 3D и на плане (`web/room.js`).
- Перетаскивание перегородок между секциями и полуперегородки зоны мышью в 3D (шаг 10 мм, Alt — точно); привязка ряда к стене (в угол, по центру, к краю) и закрытие остатка стены фальшпанелью.
- Библиотека корпусов: типовые (нижний под мойку, три ящика, верхний с подъёмником, пенал и др.) и свои, сохранённые в справочнике (`web/library.js`).
- Деление секции по высоте с вложенными колонками (дерево ячеек, `web/cells.js`).
- Декор и толщина кромки отдельных деталей, горячие клавиши секций, отмена и повтор на весь проект.

**Проверка и достоверность**
- Проверка собираемости (`web/check.js`): пересечения, парность присадки, порядок сборки, фурнитура, вес дверей, прогиб полок по формуле (`web/norms.js`), кинематика открывания.
- Автоисправление замечаний (`web/autofix.js`).

**Документация**
- Страница задания (`web/production.html`): спецификация, чертежи деталей с размерными цепочками и видом с обеих пластей (`web/partdraw.js`), план-схема (`web/plan.js`), карты раскроя с порядком резов и складскими остатками (`web/nest.js`), смета, КП, этикетки с QR, инструкция сборки по модулям, список покупок, «Полный пакет» с титулом и оглавлением для печати в PDF.
- Экспорт: CSV, DXF R12 с замкнутыми контурами и таблицей слоёв (`web/dxf.js`), CSV для сервисов раскроя, карта раскроя DXF, JSON операций ЧПУ для постпроцессора (`web/export-cut.js`), 3D в OBJ и GLB.
- Форматы конкретных программ раскроя и станков (Giblab, Viyar, .mpr, .bpp) не воспроизводятся: нужны образцы файлов.

**Платформа**
- Синхронизация, версии, шаринг по ссылке, PWA с офлайн-доступом, мобильный интерфейс.

## Тесты
```bash
./run.sh test        # тесты ядра
./run.sh servertest  # тесты сервера (поднимает временный Postgres)
./run.sh full        # полная проверка
```

При правках в `web/model*.js`, `web/export.js`, `web/nest.js`, `web/dxf.js`, `web/rules.js`, `web/check.js`, `web/project.js` обязательно запускать `./run.sh test`. Перед релизом поднимайте версию кеша: `./run.sh bump` (сервис-воркер отдаёт файлы из кеша).

## Деплой
```bash
cd deploy
cp .env.example .env
docker compose up -d --build
```

## Технические детали
- Чистый ES-модульный JS, без фреймворков
- Единицы в ядре — мм, в 3D — метры
- LocalStorage: `mebel-v3`, `mebel-projects`, `mebel-catalog`; проект несёт версию схемы `schema` (миграции в `web/rules.js`)
- Все изменения коммитятся осмысленно на русском языке
