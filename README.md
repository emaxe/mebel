# Конструктор корпусной мебели

Браузерный параметрический конструктор корпусной мебели (шкаф, стеллаж, тумба, комод, ТВ-тумба) с 3D-просмотром, расчётом, экспортом под распил и проверкой собираемости.

Работает локально-first: без сервера достаточно открыть `web/`. При желании можно поднять синхронизацию проектов, версии, шаринг и каталог через `server/` (Fastify + Postgres).

## Быстрый старт

### Только клиент
```bash
./run.sh serve
# или
npx serve .
```

Открыть `http://localhost:3000` (или порт serve). Приложение хранит проекты в `localStorage`.

### Полный стек (клиент + API + БД)
```bash
./run.sh dev
```
- Клиент: http://localhost:8088
- API: http://localhost:8088/api
- Mailpit: http://localhost:8025

## Структура
| Путь | Назначение |
|---|---|
| `web/` | Клиент: UI, ядро расчёта, 3D, экспорт, смета, проверка собираемости |
| `server/` | API: авторизация, проекты, версии, шаринг, каталог, синхронизация |
| `deploy/` | Caddy + Docker Compose для деплоя |
| `test/` | Тесты ядра (Vitest) |
| `run.sh` | Скрипты запуска, тестов, проверки |
| `AGENTS.md` | Инструкция для AI-агентов |
| `CHANGELOG.md` | История изменений |

## Ключевые возможности
- **Параметрический расчёт** — `web/model.js`, `web/model-fronts.js` строят спецификацию деталей с кромкой, отверстиями, пазами
- **3D-просмотр** — three.js 0.184, анимация открывания дверей/ящиков, проверка коллизий
- **Экспорт** — CSV (`;`, UTF-8 BOM), DXF R12 (cp1251) с разбивкой по слоям
- **Раскрой** — группировка, пильные размеры, раскрой листов
- **Смета и КП** — расчёт по справочнику, этикетки, задание на распил
- **Проверка собираемости** — `web/check.js` на пересечения, крепёж, связность
- **Инструкция по сборке** — пошаговый режим и аксонометрия
- **Синхронизация** — авторизация, проекты, версии, шаринг по ссылке
- **PWA/Service Worker** — офлайн-доступ
- **Мобильная адаптация** — bottom-sheet UI

## Тесты
```bash
./run.sh test        # тесты ядра
./run.sh servertest  # тесты сервера (поднимает временный Postgres)
./run.sh full        # полная проверка
```

При правках в `web/model*.js`, `web/export.js`, `web/rules.js`, `web/check.js` обязательно запускать `./run.sh test`.

## Деплой
```bash
cd deploy
cp .env.example .env
docker compose up -d --build
```

## Технические детали
- Чистый ES-модульный JS, без фреймворков
- Единицы в ядре — мм, в 3D — метры
- LocalStorage: `mebel-v3`, `mebel-projects`, `mebel-catalog`
- Все изменения коммитятся осмысленно на русском языке
