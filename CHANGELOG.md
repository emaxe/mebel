# Changelog

Все заметные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Редактор: числовой ввод размеров, «вписать в нишу» по общей ширине, клик по замечанию ведёт к секции, горячие клавиши секций
- Выбор детали в 3D с карточкой свойств; перетаскивание полок мышью и стрелками ↑ ↓ с привязкой к шагу 32
- Размерные линии поверх 3D с вводом размера по клику (`web/dims.js`)
- Версия схемы проекта `schema` и цепочка миграций (`migrate` в `web/rules.js`)
- Заглушки на видимые шляпки конфирматов; деление задней стенки из ХДФ, не помещающейся на лист
- DXF R12 для станков (`web/dxf.js`): замкнутый контур на деталь с выемками в углах, дуги через bulge, толщина детали, таблица слоёв с цветами, границы чертежа; опции `edges` и `labels`
- Чертежи деталей (`web/partdraw.js`): размерные цепочки до отверстий, стрелка волокон для текстурных декоров, вид с пласти B (зеркально по X)
- Универсальные выгрузки (`web/export-cut.js`): CSV для сервисов раскроя (пильные и чистовые размеры, кромка, поворот, ось волокон), карта раскроя DXF по листам, JSON операций ЧПУ (контур, присадка, пазы, фрезеровки) для постпроцессора
- Раскрой (`web/nest.js`): складские остатки в справочнике (закрываются первыми, в смету не входят), точные деловые остатки (максимальные свободные прямоугольники), порядок резов с нумерацией на карте, три способа выбора места при укладке
- Проект из нескольких модулей (`web/project.js`): основной корпус в `P`, дополнительные в `P.modules`; панель модулей в редакторе (добавить, копия, удалить, влево и вправо, зазор, подъём над полом), 3D из всех модулей с выбором кликом, общая ширина проекта в размерах, схема 2 только у проектов с модулями
- Документы проекта из модулей: общая спецификация даёт CSV, DXF, раскрой, смету, этикетки и покупки; проверки, виды и инструкции по сборке — по модулям; в метке секции указан модуль («М2·1»); просмотр по ссылке и серверная проверка учитывают модули
- Кухонные модули: нижний (царги вместо крышки, ножки), верхний (навесы, подъёмный фасад) и пенал; модуль «над предыдущим» для навесных шкафов; столешница проекта (`web/worktop.js`) над подряд стоящими нижними модулями со свесами и вырезами под мойку и варочную панель, строки в смете и операциях ЧПУ
- Угловая кухня: модуль с «Углом» начинает второй ряд вдоль соседней стены под 90° (справа или слева); ряды не пересекаются, габариты проекта — охватывающий прямоугольник; вторая столешница стыкуется встык с первой; повёрнутые модули в 3D, размеры и подсветка в их координатах
- План-схема проекта (`web/plan.js`): вид сверху с корпусами, рядами вдоль стен, столешницей и цепочками размеров на странице задания
- Декор отдельных деталей (`P.overrides`): правило «деталь, секция, декор» подменяет материал и цвет в 3D; такие детали идут в раскрой, смету и спецификацию отдельной позицией; редактор в «Параметрах»
- Цокольная планка на клипсах для корпусов на ножках (по умолчанию у нижнего модуля и пенала): деталь из фасадного материала, утоплена на 50 мм, клипсы по числу ножек
- Инварианты тестов: раскрой, структура DXF, отверстия, состав кеша сервис-воркера
- Справочник фурнитуры, смета, КП и этикетки в `production.html`
- Проверка собираемости `web/check.js` с полной валидацией
- Инструкция по сборке и аксонометрия (`web/assembly.js`, `web/axo.js`)
- Параметры фурнитуры (`web/hwparams.js`, `web/fittings.js`)
- Информация о деталях (`web/partinfo.js`)
- Просмотр задания (`web/production-view.js`)
- Расширенные тесты ядра и сервера
- Поддержка синхронизации с сервером (авторизация, проекты, версии, шаринг)
- Сервис-воркер для офлайн-режима
- Мобильная адаптация интерфейса

### Changed
- Существенно доработаны ядро расчёта (`web/model.js`, `web/model-fronts.js`), 3D (`web/build3d.js`), экспорт (`web/export.js`)
- Улучшен UI конструктора, добавлены новые возможности конфигурации
- Обновлён `run.sh` для локальной разработки и тестирования

### Fixed
- Направление текстуры у цоколя и карниза в раскрое; выбор листа ближайшей толщины
- CSV: пропадающая нулевая координата; DXF: кодировка «№», имя слоя паза
- Средний цоколь больше не закрывает конфирматы перегородки; МДФ-фасады не кромятся; проставки ящиков не заходят на планки петель
- Ссылка «поделиться» сохраняет токен при смене режима; отметки «куплено» привязаны к id проекта
- Различные правки по расчёту, кромке, отверстиям и геометрии
